Sub-millisecond smart clipboard.

Never lose a copied code snippet, link, or design asset again. Zenith indexes your clipboard in-memory with custom UTF-8 Boyer-Moore and Unicode fuzzy search for instant recall under 1 millisecond.

Zero-Leak In-Memory Eviction

Configurable history limit (20 to 500 items). Excess unpinned items are automatically evicted via thread-safe FIFO without memory bloating.

Automatic Password & Keychain Exclusion

Intelligently ignores transient data copied from 1Password, Bitwarden, Apple Keychain, and incognito browser tabs via macOS ConcealedType markers.

Keyboard-Driven Workflow

Full support for ⌘1–⌘9 instant paste, ⌘P pin toggle, ⌘⌫ delete, and Emacs navigation (Ctrl+N / Ctrl+P).

Encrypted DNS and anti-DPI.

Traditional VPNs slow down your entire connection, introduce ping spikes, and tunnel your trusted traffic through unknown data centers. Zenith uses native DNS over HTTPS and TLS ClientHello packet chunking directly on localhost.

DNS over HTTPS (DoH) Resolver

Encrypts all system DNS queries via Cloudflare (1.1.1.1) or Google DNS (8.8.8.8), preventing your ISP or local network snooper from logging domain names.

TLS ClientHello SNI Chunker

Splits the initial TLS handshake packet into dual micro-chunks. Neutralizes Deep Packet Inspection (DPI) firewalls with 0ms added latency.

100% In-Process Local Proxy

Runs strictly on 127.0.0.1:8080 with zero kernel extensions, zero third-party drivers, and auto-restoring network safety guards.
