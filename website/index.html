Zenith

Small Mac utilities in one app: an island in the notch with a dock of tools, clipboard history, screen capture and annotation, on-device OCR, a disk cleaner with an app uninstaller and a local DNS-over-HTTPS proxy. Native, open source, no analytics.

Download for macOS Source on GitHub

macOS 26 Tahoe or later · Swift 6 · MIT license

This page is a pretend Mac. Everything Zenith does can be tried on it, with made-up tracks, processes and files. Nothing leaves your browser and nothing on your computer is changed.

    Install

    1. Download the DMG from GitHub Releases.
    2. Open it and drag Zenith into Applications.
    3. Control-click Zenith, choose Open, then Open again. This is needed once, because the app is not notarized.

    Zenith then lives in the notch: rest the pointer on it and the island opens. There is no menu bar icon unless you turn one on in Settings → Dynamic Island. It checks GitHub for a new version once a day and installs one only after you click, and only if it is signed with the same certificate as the copy you run.

    Or build it from source

    git clone https://github.com/mynameisbat/zenith-macos.git
cd zenith-macos
./scripts/bundle_app.sh
open Zenith.app

    To build it: macOS 26 (Tahoe) or later, and Xcode 26 or later or the Command Line Tools with a Swift 6.2 toolchain.

    Permissions, and why

    Screen Recording needed for capture
    macOS requires it to capture the display, for the loupe and for OCR.
    Accessibility optional
    Lets Zenith press ⌘V to paste for you and send a media key when macOS refuses a playback command. Without it, items are only copied.
    Automation optional
    Lets Zenith control Music and Spotify, read Music's artwork, and ask Finder to move protected leftovers to the Trash. macOS asks once per app.
    Calendars optional
    Only for the island's calendar widget, asked when you turn the widget on.

    Careful where it matters

    Tools that delete files and change network settings should be boring and predictable. These are the rules the code follows.

    • Nothing is deleted unasked. Cleaner, uninstall and slim show what will go, then wait. Everything the uninstaller removes goes to the Trash.
    • Data that cannot be rebuilt is left alone. No Docker VM disk, no vendor folders such as Google or JetBrains, nothing touched recently.
    • Your proxy comes back. Switching Privacy Shield off, or relaunching after a crash, restores the settings you had.
    • Memory is bounded. The clipboard history keeps at most 25 MB per item and 256 MB in total.
    • Passwords stay out of the history. Copies marked concealed, and copies made in the apps you list, are not kept.
    • No analytics. The source has no tracking code. The app's own network traffic is Privacy Shield's DNS lookups and one update check a day.

    What it does not do, yet

    Not notarized
    Releases are not signed with an Apple Developer ID, so macOS warns on first launch.
    Privacy Shield is not a VPN
    It hides the names you look up, not the addresses you connect to or your IP. It covers apps that honour the system proxy, on the primary network service.
    Browser audio rests on a workaround
    macOS 15.4 and later give Now Playing data only to Apple's own programs, so Zenith reads it through the system's perl. If Apple closes this, only Music and Spotify will show.
    Leftover cleanup is conservative
    Folders of deleted apps are offered only when they look like a bundle identifier, no app from the same vendor is installed and nothing has touched them for 30 days. Nothing is ticked for you.
    This page is not the app
    It imitates Zenith's screens with made-up data. Text recognition here reads the page itself instead of running Apple Vision, and captures are drawn from a sketch of the screen.
