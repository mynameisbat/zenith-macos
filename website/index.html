What is in it

Six tools that live in the menu bar and stay out of the way. Everything runs on your Mac.

Drag over any part of the screen. The recognised text, or the payload of a QR code or barcode, goes to the clipboard.

  • Apple Vision, on device: nothing is uploaded
  • Uses the languages your system supports

Now Playing for Music, Spotify and browser audio, a charging HUD, and a shelf to park files and snippets at the top of the screen.

  • Tab titles for known media sites; other sites show the browser name

Privacy Shield

A local proxy that resolves the names of the sites you visit over DNS-over-HTTPS and splits the first TLS packet in two.

  • Cloudflare, Google, Quad9, AdGuard, NextDNS or your own
  • Your previous proxy settings are saved and restored
  • Not a VPN: your IP address is not hidden

Careful where it matters

Tools that delete files and change network settings should be boring and predictable. These are the rules the code follows. Most have automated tests; the confirmation dialogs live in the app target, which has none.

  • Nothing is deleted unasked. Cleaner, uninstall and slim show what will go, then wait.
  • Data that cannot be rebuilt is left alone. No Docker VM disk, no vendor folders such as Google or JetBrains, no recent files.
  • Your proxy comes back. Switching Privacy Shield off, or relaunching after a crash, restores the settings you had.
  • Memory is bounded. The clipboard history has hard size limits, per item and in total.
  • No analytics. The source has no tracking code. The app's own network traffic is Privacy Shield's DNS lookups.

What it does not do, yet

Better to read these here than to find out later.

Not notarized

Releases are signed ad hoc. macOS will warn on first launch until there is an Apple Developer ID behind them.

Privacy Shield is not a VPN

It hides the names you look up, not the addresses you connect to or your IP. It covers apps that honour the system proxy, on the primary network service. The packet splitting has not been verified against a real filtering network.

Some cleaners are not in the UI

Project build-folder purge, installer hunt, orphaned-leftover cleanup and the external-drive sanitizer exist in the code and have tests, but no screen reaches them yet.

Browser support is uneven

Tab titles work for Safari and Chromium browsers. Firefox has no AppleScript, so the island shows only its name, and Firefox audio detection has not been tried.

Tested on macOS 15 and 27

CI runs on macOS 15. The tests that need a window server run only on a Mac with a desktop session.

Permissions, and why

Screen Recording needed for capture

macOS requires it to capture the display, for the loupe and for OCR. It asks the first time you take a capture.

Accessibility optional

Lets Zenith press ⌘V to paste for you and send the media keys that control a browser tab. Without it, items are only copied and the island says how to allow it.

Automation optional

Lets Zenith control Music and Spotify and read the front tab of Safari and Chromium browsers for the track title. macOS asks once per app.

Install

  1. Download the DMG from GitHub Releases.
  2. Open it and drag Zenith into Applications.
  3. Control-click Zenith, choose Open, then Open again. This is needed once because the app is not notarized.

Requires macOS 14 Sonoma or later.

Or build it from source

git clone https://github.com/mynameisbat/zenith-macos.git
cd zenith-macos
./scripts/bundle_app.sh
open Zenith.app

Needs Xcode 16+ or the Command Line Tools with a Swift 6 toolchain.
